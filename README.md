About the Project

Student Marks Calculator is my first Python project. It calculates a student's total marks, percentage.
Features

- Takes the student's name as input.
- Accepts marks in Maths, Python, and English.
- Calculates total marks out of 300.

Technologies Used

- Python 3
- Visual Studio Code

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run "main.py" in the terminal.
